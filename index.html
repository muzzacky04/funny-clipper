Automated Video Clipping & Draft Preparation

Funny Clipper is a video clipping automation tool that helps creators identify interesting or entertaining moments from longer videos, create short-form vertical clips, add synchronized subtitles, and prepare selected clips for social media publishing on TikTok and YouTube.

Review Terms of Service Review Privacy Policy

Core Capabilities & Architecture

Local AI and media processing engineered for creator privacy, full transparency, and human-in-the-loop control.

Local AI Moment Detection

Funny Clipper analyzes source video segments locally using Faster Whisper for speech transcription and Ollama for intelligent highlight detection, identifying entertaining moments without relying on centralized cloud AI services.

Local FFmpeg Video Rendering

Video slicing, aspect ratio adaptation, and synchronized subtitle burning are executed locally using FFmpeg on your Windows workstation. Source video media is processed on your machine before any upload is initiated.

Dual Publishing Destinations

Supports publishing to TikTok via Content Posting API (inbox drafts via video.upload) and YouTube via YouTube Data API v3 (private video upload). Neither integration performs automatic public publishing.

End-to-End Processing & Publishing Workflow

Every step of the workflow gives the creator complete visibility, review capability, and publishing authority.

1

Source Video Ingestion

The creator provides a source video for processing. Users are legally responsible for holding all necessary rights and licenses for the media they input.

2

Local Transcription & AI Analysis

Faster Whisper transcribes speech audio, and local Ollama evaluates comedic or engaging segments locally on the workstation.

3

Local Clip & Subtitle Rendering

FFmpeg cuts selected candidates, generates vertical short-form clips, and burns formatted subtitle overlays to local output folders.

4

User Review & Selection

The creator inspects rendered clips locally, verifies editorial and copyright compliance, and explicitly chooses which clips to publish.

5

Draft / Private Upload

TikTok: Transmitted to the user's TikTok inbox as drafts.
YouTube: Transmitted to the user's channel with private visibility.

6

Manual Final Publication

The creator opens the TikTok app or YouTube Studio, verifies metadata and privacy settings, and manually initiates publication.

Platform Integration Architecture

Clear operational boundaries for third-party developer integrations.

TikTok Integration (Inbox Drafts)

Funny Clipper uses TikTok Login Kit for OAuth 2.0 authorization and the Content Posting API under the video.upload scope.

  • Uploads arrive in the creator's TikTok inbox as drafts.
  • Does not support automatic public publishing (no active video.publish scope).
  • Creator must review, caption, and publish inside the TikTok app.
  • Credentials stored locally in secrets/tiktok_token.json.

YouTube Integration (Private Uploads)

Funny Clipper integrates with the YouTube Data API v3 using Google OAuth 2.0 under the https://www.googleapis.com/auth/youtube.upload scope.

  • Uploads clips with private visibility (privacyStatus: "private").
  • Does not publish videos publicly automatically.
  • Creator inspects and adjusts visibility through YouTube Studio.
  • Credentials stored locally in secrets/youtube_token.json.

Local Orchestration & Security

Funny Clipper runs on the user's Windows environment using a local n8n workflow pipeline.

  • No centralized SaaS backend or hosted user database is maintained.
  • External network requests occur only for OAuth and publishing calls.
  • Users retain full custody of local tokens and output directories.
  • Tokens can be deleted locally or revoked on platform dashboards.

Human-in-the-Loop Guarantee: Funny Clipper does not provide automated public publishing to either TikTok or YouTube. Every uploaded clip is staged as an inbox draft (TikTok) or private video (YouTube), requiring manual creator inspection and publication. No guarantees of viral reach, view counts, or monetization are made.
