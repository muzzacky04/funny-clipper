Automated Video Clipping & Draft Preparation

Funny Clipper is a video clipping automation tool that helps users identify interesting or entertaining moments from longer videos, create short-form clips, add subtitles, and prepare selected clips for social media publishing.

Review Terms of Service Review Privacy Policy

Core Capabilities

Designed to streamline video editing workflows while keeping full publishing control in user hands.

Automated Moment Detection

Funny Clipper analyzes source video material to locate highlights, humorous clips, and engaging segments based on audio or visual pacing cues.

Automated Subtitling

The tool renders accurate, synchronized subtitle overlays suitable for vertical mobile video consumption, improving accessibility and audience comprehension.

Draft to TikTok Inbox

Integrated via the official TikTok Content Posting API using the video.upload scope. Videos arrive directly in your TikTok inbox as drafts for final manual review.

Workflow & Human-in-the-Loop Review

Every step of the clipping and uploading lifecycle is transparent, user-controlled, and audited.

1

Source Ingestion

User designates or provides a source video for processing. Users must hold all necessary rights and licenses for the media they supply.

2

Highlight & Subtitle Generation

Funny Clipper identifies candidate segments, cuts short-form clips, and creates synchronized vertical subtitles.

3

User Review & Selection

The user inspects the candidate clips locally, verifies editorial quality, copyright compliance, and chooses which clips to upload.

4

Inbox Draft Upload

Selected clips are transmitted to the user's authenticated TikTok account inbox as private drafts. Funny Clipper never publishes publicly on its own.

5

Final Publication in TikTok

The creator opens the TikTok mobile application, inspects the draft video, adds captions/tags, and manually presses Publish.

TikTok Developer Integration Details

Technical transparency for users, reviewers, and developer platform auditors.

Login Kit & OAuth 2.0

Users authenticate explicitly through TikTok's official OAuth 2.0 authorization dialog. Funny Clipper requests only the least privilege necessary to complete the draft upload operation.

Content Posting API (video.upload)

Funny Clipper uses the TikTok Content Posting API with the video.upload scope strictly to stage user-selected videos in the creator's TikTok inbox as drafts.

Local Execution & Credential Control

Funny Clipper operates as a local Windows application. Authentication tokens reside on the user's local operating system filesystem. Users retain full control to delete local credentials or revoke access at any time.

Note on Automated Publishing: Funny Clipper does not provide automatic public publishing. All uploaded media requires manual creator inspection and publication within the official TikTok application. No claims of viral reach, view counts, monetization, or algorithmic favorability are made.
